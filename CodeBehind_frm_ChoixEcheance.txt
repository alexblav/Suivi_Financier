' =====================================================================================
' CODE À COLLER DANS LE MODULE DE LA FEUILLE "frm_ChoixEcheance"
' =====================================================================================
' Pourquoi cette étape manuelle ?
'   En VBA, les "événements" d'une feuille (ici : quitter la feuille) doivent obligatoirement
'   être écrits dans le module de code de LA FEUILLE ELLE-MÊME. On ne peut pas les livrer dans
'   un fichier .bas. Ce code ne fait qu'appeler mod_ChoixEcheance, où se trouve la logique.
'   (Le détail de l'échéance choisie est fait de formules : il n'a besoin d'aucun événement.)
'
' COMMENT FAIRE :
'   1. Alt+F11 pour ouvrir l'éditeur VBA.
'   2. Dans l'explorateur de projet (Ctrl+R si absent), repérez la ligne :
'          <CodeName> (frm_ChoixEcheance)
'      (le CodeName vous est indiqué dans le message de fin d'installation).
'      Double-cliquez dessus.
'   3. Collez-y LES LIGNES CI-DESSOUS, à partir de "Private Sub Worksheet_Deactivate".
'   4. Ne collez pas ce code dans une autre feuille : il s'y déclencherait à tort.
' =====================================================================================

' Verrou "modal" : tant que le formulaire est ouvert, impossible de le quitter en changeant d'onglet.
Private Sub Worksheet_Deactivate()
    mod_ChoixEcheance.ChoixEcheanceVerrouiller Me
End Sub
